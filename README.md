# Cross-Corpus Dynamic Topic Modeling

Code accompanying the paper **“Dynamic Topic Modeling for Cross-Corpus Temporal Analysis”**, accepted at CIKM 2026.

This repository contains implementations of shared-backbone dynamic embedded topic models, source-to-corpus adaptation, evaluation, sensitivity analyses, and topic trajectory analysis.

## Repository Structure

- `DETM_weights/`: model training, adaptation, evaluation, and analysis code
- `data_processing_scripts/`: corpus preprocessing utilities
